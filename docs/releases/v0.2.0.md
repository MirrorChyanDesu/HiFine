## 看图与文件操作

- 左侧新增文件夹缩略图。单击即可跳到对应图片，用方向键翻页时，列表会跟随当前照片滚动。
- 连续翻页时，HiFine 会优先预读翻页方向的相邻图片。往回翻可以复用已经解码的图像和拍摄信息。
- 可以右击主图或任意缩略图。在 Windows 上可使用资源管理器的经典右键菜单，在 macOS 和 Linux 上可在文件管理器中定位图片。右击其他缩略图时，主图会保留当前照片。
- 修复了文件夹中最后一张图片被编辑器删除再以原名保存时，主图和缩略图未能恢复的问题。
