HiFine 首个桌面版本支持 Windows、macOS 和 Ubuntu，可直接打开相机的 HIF / HEIF / HEIC 照片，也支持 JPEG、PNG、GIF、WebP、BMP、TIFF、ICO 和 AVIF。

## 开始看图

- 将照片拖入窗口，用 ← / → 浏览同一文件夹，滚轮缩放，按住鼠标左键拖动放大的照片。
- 按 Tab 查看照片尺寸、文件大小及 EXIF 拍摄信息，按 F11 进入全屏，按空格暂停或继续播放 GIF 和动画 WebP。
- Windows 安装完成后，在图片的“打开方式”中选择 HiFine 并设为默认，即可双击打开该格式。安装包自带 HIF、HEIF、HEIC 的资源管理器缩略图扩展。

本版以 8 位预览显示高位深 HIF。macOS 版采用 ad-hoc 签名，尚未经 Apple 公证。Finder 的 Quick Look 缩略图使用系统 ImageIO 解码，不同相机 HIF 的兼容性仍待实机验证。[安装与文件关联说明](https://github.com/MistEO/HiFine/blob/v0.1.0/README.md)
